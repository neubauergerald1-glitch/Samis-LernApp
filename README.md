# Touchdown Lernapp

Lern-App im Flag-Football-Stil: Karteikarten (Huddle), Quiz-Drives bis zum Touchdown und Two-Minute Drill.

- Biologie (Evolution & Erdzeitalter) ist fest eingebaut.
- Weitere Fächer lassen sich in der App über „+ Fach hinzufügen“ anlegen.
- Fortschritt und eigene Fächer werden im Browser des Geräts gespeichert.

Die ganze App steckt in `index.html` und läuft über GitHub Pages.
